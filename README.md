# 🎬 SeriesHub - הנטפליקס הפרטי שלך במחשב

מערכת ווב מקומית מודרנית לניהול, מיון והזרמת פרקי סדרות ישירות מתיקיית ההורדות במחשב שלך. מותאמת במיוחד לתבניות השמות והקידודים הנפוצים בישראל (כגון: *האי*, *שכונה*, *חצויה*, *פלמ"ח*, *נעלמים*, *ספיידרז*, *ג'ינג'י*, *הנפילים* ועוד).

---

## ✨ תכונות מרכזיות

* **🎨 עיצוב Glassmorphism יוקרתי:** ממשק כהה ועמוק עם אפקטי זכוכית מטושטשת (`backdrop-filter: blur`), הדגשות ניאון סגול/טורקיז ויישור מלא לימין (RTL).
* **🧠 מנוע זיהוי ישראלי חכם:** מפענח באופן אוטומטי שמות סדרות, עונות ומספרי פרקים ממגוון פורמטים (`עונה 1 פרק 5`, `ע1פ30`, `S01E05`, פרקים כפולים כמו `פרק 1+2`).
* **⚡ 100% אופליין ועצמאי:** כרטיסיות מעוצבות עם גרדיאנטים ייחודיים ומחווני התקדמות ללא תלות בחיבור חיצוני.
* **🛡️ אפס מחיקות ואפס אובדן מידע:** סריקה בטוחה לחלוטין. שום קובץ לעולם לא נמחק, כולל גרסאות כפולות `(1).mp4`.
* **📁 ארגון פיזי בטוח לתיקיות מסודרות:** כפתור מובנה בממשק שממיין בבטחה את הקבצים מתיקיית ההורדות למבנה היררכי `סדרות\<שם הסדרה>\עונה <X>\` מבלי לדרוס או לאבד אף קובץ.
* **🍿 תמיכה בכל הפורמטים:**
  * **נגן וידאו מובנה בדפדפן:** הזרמה מהירה (HTTP Range Streaming) עם דילוג חלק עבור קבצי `.mp4` ו-`.webm`.
  * **פתיחה בלחיצה בנגן מקומי (VLC / נגן Windows):** אידיאלי עבור קבצי `.mkv` ו-`.avi` עם קידודים כבדים וסאונד היקפי.
* **📊 מעקב צפייה חכם:** סימון אוטומטי/ידני של פרקים שנצפו, מחוון אחוז התקדמות לכל סדרה, ובאנר "המשך מאיפה שעצרת".
* **📱 צפייה בכל מכשיר בבית (Wi-Fi):** אפשרות לגלוש לאתר מהסמארטפון, הטאבלט או הטלוויזיה החכמה באותה רשת ביתית.

## 🚀 איך מפעילים?

### הפעלה מהירה (בלחיצה כפולה):
פשוט לחץ פעמיים על הקובץ:
```text
start.bat
```
השרת ייפתח אוטומטית בדפדפן בכתובת: `http://localhost:5000`.

### הפעלה ידנית מטרמינל:
1. התקן את התלויות (פעם אחת בלבד):
   ```bash
   pip install -r requirements.txt
   ```
2. הפעל את השרת:
   ```bash
   cd backend
   python -m uvicorn app:app --host 0.0.0.0 --port 5000
   ```
3. פתח את הדפדפן בכתובת: `http://localhost:5000`.

## 📂 מבנה התיקיות בפרויקט

```
series-hub/
│
├── backend/
│   ├── app.py             # שרת FastAPI (הזרמת וידאו, API לנגן מקומי וניהול)
│   ├── scanner.py         # מנוע סריקה וזיהוי שמות סדרות ועונות בעברית/אנגלית
│   ├── organizer.py       # מנוע ארגון קבצים בטוח לתיקיות סדרה ועונה
│   └── database.py        # שמירת היסטוריית צפייה מקומית
│
├── frontend/
│   ├── index.html         # ממשק משתמש ב-RTL (עברית)
│   ├── style.css          # עיצוב Glassmorphism וניאון
│   └── app.js             # לוגיקת צפייה, חיפוש, סינון ונגן
│
├── start.bat              # קובץ הפעלה מהיר בלחיצה כפולה
├── requirements.txt       # ספריות פייתון (FastAPI, Uvicorn)
├── .gitignore             # מניעת העלאת סרטים כבדים ל-GitHub
└── README.md              # קובץ תיעוד זה
```
